# 调试呈现验证记录

## Value 转换

在 x86-64 上运行 `cargo test --locked --lib conversion_batches_reads_and_preserves_cycles -- --nocapture`。测试使用同一 QuickJS 运行时和模拟目标内存。耗时包括宿主读取接口到 JS 的传输和解码。内存是测量前后 QuickJS 分配量的差值。读取数统计目标读取接口调用，临时 Value 数统计测量期间创建的原生 Value。单次样本仅用于观察量级。

| 场景 | 耗时 | QuickJS 分配量差值 | 读取次数 | 读取字节 | 临时 Value |
| --- | ---: | ---: | ---: | ---: | ---: |
| 32,768 个 u32 的数组，格式化前 4 项 | 0.29 ms | 3,184 B | 1 | 16 | 0 |
| 32,768 个 u32 转换 | 138 ms | 661,976 B | 8 | 131,072 | 0 |
| 16,384 个双字段结构体转换 | 337 ms | 5,380,688 B | 8 | 131,072 | 0 |
| 16,384 个指针的数组，共转换两次 | 192 ms | 603,456 B | 16 | 262,144 | 0 |
| 32 KiB C 字符串转换 | 56 ms | 2,016 B | 10 | 36,872 | 0 |
| 裁剪格式化和完整转换交替执行三次 | 355 ms | 1,981,328 B | 27 | 393,264 | 0 |
| 512 个预先注册的自定义 Formatter | 23 ms | 1,048,800 B | 0 | 0 | 0 |

数组显示前 4 项时读取 16 字节，完整转换读取 131,072 字节。用例也校验循环引用保留对象身份、Formatter 递归保护和拒绝隐式数值转换。
